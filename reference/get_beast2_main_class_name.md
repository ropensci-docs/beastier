# Get the BEAST2 main class name.

One way to fix the error `no main manifest attribute` is to specify the
main class name.

## Usage

``` r
get_beast2_main_class_name()
```

## Value

the BEAST2 main class name

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
get_beast2_main_class_name()
#> [1] "beast.app.beastapp.BeastLauncher"
```
