# Get the default BEAST2 version that is used by beastier

Get the default BEAST2 version that is used by beastier

## Usage

``` r
get_default_beast2_version()
```

## Value

the BEAST2 version

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beaustier_folders()

get_default_beast2_version()
#> [1] "2.6.0"

check_empty_beaustier_folders()
```
