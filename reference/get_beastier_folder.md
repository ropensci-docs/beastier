# Get the path to the [beastier](https://docs.ropensci.org/beastier/reference/beastier-package.md) temporary files folder

Get the path to the
[beastier](https://docs.ropensci.org/beastier/reference/beastier-package.md)
temporary files folder.

## Usage

``` r
get_beastier_folder()
```

## Value

the path to the
[beastier](https://docs.ropensci.org/beastier/reference/beastier-package.md)
temporary files folder.

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
get_beastier_folder()
#> [1] "~/.cache/beastier"
```
