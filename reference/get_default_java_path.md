# Obtains the default path to the Java executable

Obtains the default path to the Java executable

## Usage

``` r
get_default_java_path(os = rappdirs::app_dir()$os)
```

## Arguments

- os:

  name of the operating system, must be `unix` (Linux, Mac) or `win`
  (Windows)

## Value

the default path to the Java executable
